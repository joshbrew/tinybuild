# JavaScript page with live reload

## Run

```sh
npm install
npm start
```

Follow the printed URL. Stop development with Ctrl+C.

## Try it

Start a plain page with JavaScript and imported CSS.

A green Hello World square moves around the page. Change its text in `index.js` or its appearance in `index.css`, save, and watch the page update.

Run `npm run check` to verify the build when needed. The complete `tinybuild.config.js` explains all settings. [Agent guide](node_modules/tinybuild/tinybuild/docs/agents.md).
